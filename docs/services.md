## 可承接的服务

### 🌐 后台管理系统 / 全栈项目开发

基于 Spring Boot 3 + Vue 3 + UniApp 企业级架构,承接各类**后台管理系统**(企业管理后台、运营管理平台、数据中台)、SaaS 平台、商城、物联网平台等中大型项目,覆盖多租户、RBAC 权限体系、代码生成、支付、监控告警等企业级能力,后台 + 前端 + 移动端一体交付。

### 🖥️ 桌面软件开发

跨平台桌面应用开发,基于 Tauri 2.x 技术栈,一套代码覆盖 Windows / macOS / Linux。适用于工具软件、管理客户端、数据处理工具、AI 桌面应用等场景,体积小、性能高、安全可控。

### 📱 微信小程序 / 公众号

微信小程序、公众号、H5、App 全端覆盖,一次开发多端发布,支持小程序与公众号深度集成。

### 🤖 大模型与 Agent 应用

大模型应用与 Agent 工程落地:RAG 检索增强、工具调用(Tool Use)、多智能体编排、知识库工程化、MCP 接入,助力业务智能化升级。
