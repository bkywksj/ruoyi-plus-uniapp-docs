# 特性

核心理念

代码即文档 - 通过规范化命名和完善注释实现代码自解释
全栈统一 - 前后端命名规范、类型定义、接口管理保持一致
开发友好 - 注重开发体验和可维护性，减少冗余代码

🔧 后端框架特性
基础架构增强

Service层重构 - 封装基础Service接口和实现类，支持泛型适配
查询增强 - LambdaQuery、PlusQuery工具，支持聚合函数和条件自动处理
统一返回格式 - {{ 'R<T>' }}标准响应结构，PageResult分页封装

权限与安全

数据权限控制 - BaseDataPermissionMapper接口，支持细粒度权限控制
多租户架构 - 完整的租户数据隔离，支持租户开关控制
统一认证体系 - 抽象认证策略，支持多种登录方式（账密、手机号、微信等）

业务功能模块

字典系统重构 - 统一字典枚举命名（Dict前缀），规范化字典值
文件存储 - 支持多种OSS（S3、阿里云、腾讯云、七牛云等）和本地存储
代码生成 - 主子表生成、Excel导入功能、模糊搜索自动生成
支付集成 - IJPay支付模块，支持多种支付方式
消息推送 - 公告系统、SSE实时通信、WebSocket支持

数据库设计规范

表命名规范 - a_xxx（业务表）、b_xxx（基础服务表）、c_xxx（商城表）
字段统一 - 逻辑删除(isDeleted)、状态控制(status)、租户隔离(tenantId)
索引优化 - 针对租户和业务查询的索引策略

国际化支持

后端国际化 - 统一错误码和消息管理，支持多语言响应
正则表达式池 - 集中管理各种验证规则和国际化键

🎨 前端框架特性
架构优化

组合式API重构 - 全面采用Composition API，hooks化所有工具函数
统一状态管理 - Pinia模块化，useXxxStore命名规范
类型安全 - TypeScript全覆盖，与后端VO/BO类型一致

开发体验

组件命名规范 - 驼峰命名，取消index.ts，便于快速定位
工具函数重构 - utils目录按功能分类（date、string、crypto、validators等）
自定义指令增强 - 权限控制、复制文本等指令，支持延迟加载组件

UI/UX优化

UnoCSS集成 - 原子化CSS，统一设计系统（颜色、间距、字体）
图标系统 - 统一使用Iconify海量图标库，分类管理
响应式布局 - 表格自适应高度、跨页选择、媒体查询优化

业务组件

表单组件 - AFormXxx系列组件（日期、上传、编辑器等）
表格工具 - useTableHeight、useSelection跨页选择
搜索组件 - ASearchForm统一搜索栏容器
富文本编辑器 - 基于Tiptap的UMO Editor，支持图片/视频上传

国际化系统

菜单国际化 - 根据路径和权限标识自动生成国际化键
组件国际化 - ElementPlus资源集成，统一翻译函数

📱 移动端框架特性
基础架构

Uni-app集成 - 跨平台移动端解决方案
模块化管理 - 分包结构，示例代码与业务代码分离
配置统一 - 应用ID、加密解密与后端保持一致

UI组件库（wot-ui-design重构）

导航系统 - wd-navbar支持胶囊组件、高度自适应
表单组件 - 完整的表单控件体系（input、picker、upload等）
展示组件 - 图片、视频、表格、图表等展示组件
交互组件 - 弹窗、提示、加载、下拉刷新等

移动端特色

rpx单位统一 - 更好的移动端适配体验
双向绑定优化 - 支持字符串和数组的灵活绑定
触摸交互 - 手势操作、滑动组件、签名组件等

小程序集成

微信生态 - 小程序登录、公众号登录
UnionID绑定 - 统一用户身份管理
自动更新 - WebSocket/SSE检测更新机制

🔄 全栈协同特性
接口规范

RESTful设计 - 统一的API路径和方法命名
类型同步 - 前后端VO/BO类型定义一致
错误处理 - 统一的错误码和国际化消息

开发工具

代码生成 - 前后端代码同步生成
Docker支持 - 完整的容器化部署方案
开发调试 - 远程调试、热重载支持

数据流转

实时通信 - SSE、WebSocket双向通信
文件处理 - 统一的文件上传、下载、预览机制
缓存策略 - Redis缓存与前端状态管理联动
