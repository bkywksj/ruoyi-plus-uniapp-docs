# /loop-gen - 按当次意图，现生成一条量身定做的 /loop 提示词

你不一定每次都是「按需求文档建功能」——有时是**还原原型**、有时是**修一批 SEO 问题 / 补测试 / 迁移写法 / 批量改文案 / 清理**。
本命令听你一句意图，产出一条**填好真相源 / 每轮动作 / 验证门 / 停止条件**的 `/loop` 提示词，你直接粘贴起飞。

> 和邻居的分工：`/dev-loop` = 固定 SOP（按任务台账建功能，最常用）；**`/loop-gen` = 意图不固定时现生成一条**；`/kickoff` = 从零起新站点的完整流水线；`/dev-orchestrate` = 智码里按台账建功能的多会话编排版。

## 用法

```
/loop-gen <一句话意图>
```

例：
- `/loop-gen 把现有页面逐页还原成 docs/prototypes/ 的原型（截图比对修正）`
- `/loop-gen 把 pnpm check:seo 的警告一条条清干净`
- `/loop-gen 给 src/lib 下每个模块补单测`
- `/loop-gen 把所有分类的 description 改写成「X 是 Y」定义句并逐条核对`
- `/loop-gen 把全站外链封面迁移到构建期优化（imageDomains + resolveCover）`

## 生成步骤

1. **归类意图**到一种循环范式：建功能 / 还原 UI / 修问题 / 补测试 / 迁移写法 / 批量改内容 / 清理 / 文档。
2. **摸项目**（真相源、验证命令、技术栈），缺关键信息就**只问你 1-2 个**：
   - 每轮「一项」的粒度？（一页 / 一个组件 / 一条警告 / 一个集合 / 一篇文章）
   - 每轮「算完成」的判据？（build 过 / check:seo 该条消失 / 测试过 / 截图对齐原型 / diff 符合预期）
   - 范围？（全量 / 某目录 / 某清单）
3. **套通用骨架**（见下），按意图把 `<尖括号>` 占位填实。
4. **UI 类意图自动加「原型保真截图闭环」**；非 UI 不加（别画蛇添足）。
5. **整段输出提示词**给用户——⚠️ **开头第一行必须是 `/loop`**（否则用户粘进去不会进入自主循环、只跑一次）。说明：在本项目新开会话整段粘贴即可起飞；想圈范围在正文「现在开始」那行自己加。
6. **在【智码 AICoder】里时，追加一份「智码编排版」**（检测：`echo $AICODER_SESSION_ID` 非空，或 `mcp__aicoder__get_session_status` 可调）——见下方「智码编排版输出」。两份都给，并按规模给推荐：清单 ≥ 5 项或需要异构验收 → 推荐编排版；否则推荐 `/loop` 版。

## 智码编排版输出（仅在智码里追加）

智码的「协同编排」弹窗（状态栏「编排」）本身就是一段通用总控提示词：本会话当总控，派实现子会话、另开验收子会话、跑完自动唤醒。
意图不固定的长任务不必新写命令，**把上面填好的骨架折算成弹窗变量**给用户逐项填：

| 弹窗变量 | 怎么填 |
|---------|--------|
| 任务目标 | 意图一句话 + 「按清单逐项推进，每项一个最小可验证单元，做完规范提交」+ 真相源路径 |
| 验收标准 | 骨架里的「验证门」+「停止条件」原文（命令写全：`pnpm build`、`pnpm check:seo`、`pnpm test`） |
| 实现模型 | 默认 `claude-code`（本项目斜杠命令、技能、CLAUDE.md 禁令都只在 Claude 侧齐全） |
| 验收模型 | 默认 `codex`（异构交叉验证）；UI 还原类可选同为 `claude-code`（需要智码浏览器截图比对） |
| 最大驳回轮次 | 2（与 dev-loop「同一项 2 轮修不过即熔断」一致） |

> 若意图就是「按 `docs/tasks/active/` 台账建功能」，别走弹窗，直接推荐 `/dev-orchestrate`——它带本项目的验证门、两段 review 和红线，通用弹窗不懂这些。

## 约束

- 生成的提示词必须**填实**所有 `<尖括号>` 占位（用项目真实路径 / 命令），不要把占位符原样给用户。
- **提交类型按意图选**，别一律 feat/fix（口径见 `CLAUDE.md`「提交与进度口径」，只有 feat / fix 计入业务进度）：

| 意图 | 提交类型 |
|------|---------|
| 建功能 / 还原 UI | `feat(scope)` |
| 修问题 / 修 SEO 警告 / 改文案 | `fix(scope)`（SEO 类用 `fix(seo)`） |
| 补测试 | `test(scope)` |
| 迁移写法 / 清理 / 重构 | `refactor(scope)` |
| 同步数据 | `chore(data)` |
| 文档 | `docs(scope)`（台账与三文档用 `docs(tasks)`） |
| 孵化项目里改框架核心文件 | 单独提交，scope 写 `framework` |

- 验证命令贴本项目技术栈：`pnpm build`（含 `astro check`）、`pnpm check:seo`、`pnpm test`；E2E 回归可用 `pnpm test:e2e`（需先 `pnpm exec playwright install chromium`）。
- 反捏造：不确定的真相源路径或完成判据，先问用户，别瞎填。
- 本命令只**生成提示词**，不替用户起飞循环（生成后由用户粘贴运行）。
